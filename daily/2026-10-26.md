### FORCA: A Force-Aware Coding Agent for Contact-Rich Robot Manipulation

**Metadata:** arXiv 2610.31841v1 · New paper · First submitted 2026-10-22 19:24:48 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** A coding agent uses RGB-D and wrist force/torque logs to generate and revise Python contact-probing and force-feedback programs. Experience is retained in executable control logic, without task-specific model training.

**Evidence:** On a UR5e, frozen programs succeed in 10/10 drawer and 10/10 door trials, versus 4/10 and 1/10 for the same vision-only model. Moving-vase marker removal is 93% versus 21%; contact loss is 1.6% versus 55.9%, averaged over 10 trials.

**Limitations:** Five real tasks, one model, small trial counts. Each development run permits 20 physical rollouts and four hours; humans authorize execution, reset scenes and judge final acceptance. The ablation changes access to force feedback and routines together, not just memory. Reasoning costs 4–10 minutes per iteration.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.31841) · [Reviewed version](https://arxiv.org/abs/2610.31841v1) · [Full text](https://arxiv.org/pdf/2610.31841v1) · [Project](https://tanoom.github.io/forca/). Project and videos verified; no paper-specific code link found on the project page.

### RoboCode: Learning Reusable Action Primitives for Robot Manipulation

**Metadata:** arXiv 2610.32225v1 · New paper · First submitted 2026-10-23 06:32:09 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** Learns a shared soft-compositional primitive codebook from pooled action chunks, then freezes its decoder and trains task-specific state-to-code encoders.

**Evidence:** Five state-based ManiSkill tasks use 4,620 demonstrations and matched state inputs. Average success is 75.6%, versus ACT 68.8%, larger Diffusion Policy 41.6%, and compact Diffusion Policy 18.8%; LiftPegUpright improves from ACT’s 56% to 80%.

**Limitations:** Simulation only, with object poses/goals rather than image-language observations. Task-specific encoders are trained for the evaluated tasks; reusable codes are not evidence of online skill growth or unseen-task transfer. No multi-seed uncertainty or closed-loop trial count was established in the checked evaluation section.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.32225) · [Reviewed version](https://arxiv.org/abs/2610.32225v1) · [Full text](https://arxiv.org/pdf/2610.32225v1). No official project or code link identified in the abstract/full text.

### LogLook: Execution-Grounded Memory for Frontier-Model Robot Planners

**Metadata:** arXiv 2610.32348v1 · New paper · First submitted 2026-10-23 08:43:15 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** Pairs an immutable execution log and verbatim note history with expectation-gated action frames and skim-then-inspect demonstrations. GPT-6 Astra plans either waypoints or grounded π0.5 subgoals; the memory is an inference-time interface, not parameter adaptation.

**Evidence:** Controlled motion-planner comparison: 237/256 (92.6%) versus note-only 234/256 (91.4%), with 40.5k versus 71.3k tokens and 46 versus 114 images per episode. With π0.5 both memories achieve 104/128 (81.2%). Full 800-episode RoboMME scores are 93.5% direct control and 81.9% learned execution.

**Limitations:** The clean memory comparison demonstrates cost savings, not a clear success gain. Full-system gains also change action/call interfaces; direct control uses depth, calibration and task notes derived from success-checking code. One simulated benchmark and proprietary model, no real robot. Single-component failures differ by only 2–4 episodes.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.32348) · [Reviewed version](https://arxiv.org/abs/2610.32348v1) · [Full text](https://arxiv.org/pdf/2610.32348v1) · [Project](https://bingaochen.github.io/Astra-on-RoboMME) · [Code](https://github.com/bingaochen/Astra-on-RoboMME). Linked repository is accessible but its README describes an earlier three-tier monitor system with 79.13%, not this LogLook configuration; exact reproduction release is unverified.

### Semantic Representation for Agentic Self-Play in Automated Laboratories

**Metadata:** arXiv 2610.32755v1 · New paper · First submitted 2026-10-23 15:00:16 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** VERID maintains a persistent semantic laboratory twin with introspection, pre-execution simulation gates, synchronized traces and resumable state. Agents retain physical operating bounds and analytical lessons across runs.

**Evidence:** Three physical dye/water case studies demonstrate geometry rejection, communication-fault recovery and diagnostic self-play. In a three-challenge comparison, inherited multi-cycle lessons lead from 307 to 58 millinats mean composition/concentration loss across challenges 2A→2B; within challenge 1, multi-cycle scores 85 versus single-cycle 205.

**Limitations:** These are small case studies, not an isolated causal memory ablation: challenge instances and experimental strategies change. Uses a structured harness, internal Gemini checkpoint and operator approval gates in supervised runs. Biological discoveries and broad robot-policy transfer are not demonstrated.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.32755) · [Reviewed version](https://arxiv.org/abs/2610.32755v1) · [Full text](https://arxiv.org/pdf/2610.32755v1) · [PDF](https://arxiv.org/pdf/2610.32755v1). No public implementation link found in the checked paper.

### RynnUnify: Towards Unified Embodied Brain

**Metadata:** arXiv 2610.32965v1 · New paper · First submitted 2026-10-23 17:54:07 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** A Cosmos3-based 16B model couples an 8B reasoner and 8B video generator. Cross-chunk scene frames support interleaved visual planning; a separately RL-trained reasoner chooses whether to request generated evidence, and WAM adaptation adds joint video-action learning.

**Evidence:** Selected-20 RoboCasa365: 51.5% over 200 episodes, versus CMA 47.0% and Cosmos3 45.0%. Astribot S1: three tasks × 20 trials, complete-task success 46.7% on average versus GR00T N1.7 26.7% and π0.5 25.0%; these are not stage-completion scores.

**Limitations:** Robot adaptation uses roughly 1,600 hours of atomic and 177 hours of composite RoboCasa data. Full-split baseline numbers are imported from reports, whereas Selected-20 is evaluated by the authors. Visual history is within-episode context, not demonstrated lifelong memory; three real tasks do not isolate memory’s contribution.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.32965) · [Reviewed version](https://arxiv.org/abs/2610.32965v1) · [Full text](https://arxiv.org/pdf/2610.32965v1) · [PDF](https://arxiv.org/pdf/2610.32965v1) · [Project](https://alibaba-damo-academy.github.io/RynnUnify.github.io/) · [Code](https://github.com/alibaba-damo-academy/RynnUnify) · [Checkpoint](https://huggingface.co/Alibaba-DAMO-Academy/RynnUnify-WAM-RoboCasa). ### FLORA: An Open Model Suite for Scaling Robotics Data Engines

**Metadata:** arXiv 2610.31779v1 · New paper · First submitted 2026-10-22 18:16:17 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** An open labeling suite supplies temporal segments, intended-action captions and outcome/dense/rubric rewards for robotic data pipelines; segmentation/captioning use RL post-training, while the released reward model uses SFT.

**Evidence:** WGO-Bench segmentation F1 is 50.3%, but joint F1 34.5% trails Astra 39.0%. RoboRewardBench MAE is 0.400 versus Astra 0.554 (paper scales by 100). On 40 dense-reward episodes/4,861 steps, failure recall is 53.3%, but about 11% of normal steps are false failures.

**Limitations:** Not uniformly best across metrics; systems use different frame budgets/compute. The approximately 125× cost claim assumes GPU pricing and modeled throughput, omits deployment overhead, has unverified production GPU-hour accounting, and is not fully reference-version matched. No direct downstream policy-learning improvement is established here.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.31779) · [Reviewed version](https://arxiv.org/abs/2610.31779v1) · [Full text](https://arxiv.org/pdf/2610.31779v1) · [Project](https://research.nvidia.com/labs/gear/flora/) · [Checkpoint](https://huggingface.co/collections/nvidia/flora). ### KiRoSe: Using Kinematic Data for Efficient Segmentation of Robot Demonstrations

**Metadata:** arXiv 2610.31801v1 · New paper · First submitted 2026-10-22 18:40:43 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** Compresses shared 14-D bimanual kinematics into transition-supervised Sparse Motion Tokens at two tokens/second; a LoRA-adapted language model predicts temporal segments and descriptions, with transfer to new robots and human hands.

**Evidence:** Trains on 5,478 YAM episodes. On 200 held-out episodes, boundary F1 at ±1 second is 0.63 versus approximately 0.41–0.42 for FAST/OAT/MotionGPT interfaces; lexical/embedding grounded F1 is 0.43/0.49. Cross-embodiment evaluation includes 2,653 AgiBot and 193 human-hand trajectories without target training.

**Limitations:** The encoder uses whole-episode normalization and symmetric temporal context, so it is offline. Tokenizer comparisons differ in input representation and reader-training populations, not just objective. Segmentation/semantic transfer does not establish closed-loop robot-policy gains.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.31801) · [Reviewed version](https://arxiv.org/abs/2610.31801v1) · [Full text](https://arxiv.org/pdf/2610.31801v1) · [Project](https://berkeleyautomation.github.io/kirose/) · [Checkpoint](https://huggingface.co/collections/sy-xie/kirose-6ad95aa4a31c20b5aec06ca1). ### Lifelong Context Adaptation through Bidirectional Memory-Skill Learning

**Metadata:** arXiv 2610.32295v1 · New paper · First submitted 2026-10-23 07:53:18 UTC. Review: Full-text methods, key experiments, and limitations checked; author-reported results, not independently reproduced.

**Contribution:** MemCryst freezes the language model and co-evolves external episodic/factual memory and conditional skills. Repeated episodes support skill creation/revision; task outcomes adjust future retrieval weights without rewriting served records.

**Evidence:** On a matched 600-task ALFWorld stream, joint serving succeeds on 63.17%, versus 59.83% for memory-only and 50.50% for skill-only serving. Four shuffled orders average 61.08% with 2.96-point sample SD. Frozen-state controls use 100 held-out tasks and a 1,024-token context limit.

**Limitations:** Text-based simulation, not real robot control. Skill-only serving still retains internal memory for learning skills. Outcome credit is shared by all served records, not individual causal attribution; feedback noise and transfer to unseen domains are untested. Task order matters.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.32295) · [Reviewed version](https://arxiv.org/abs/2610.32295v1) · [Full text](https://arxiv.org/html/2610.32295v1) · [Code](https://github.com/tianyi0216/Memcryst). Public repository verified with source, configurations, tests, ALFWorld and ablation launchers; not executed.

### LeafSkill: Efficient Leaf-Level Action Grounding for Recursive LLM Agents

**Metadata:** arXiv 2610.32412v1 · New paper · First submitted 2026-10-23 09:38:15 UTC. Review: Full-text methods, key experiments, and limitations checked; author-reported results, not independently reproduced.

**Contribution:** An external retrieve–bind–select layer reuses leaf-level action grounding while retaining the original recursive planner. A LoRA-trained 1.7B selector chooses an admissible bound action or defers to the unchanged host.

**Evidence:** On an independent 200-task Robotouille set, success is 137/200 versus ReCAP 121/200 (68.5% versus 60.5%, exact McNemar p=.0259). On 106 common successes, host tokens fall 14.42% and calls 14.08%. Expanding 446 to 588 skills improves fixed-set token savings from 18.35% to 25.64%, but success changes from 137/200 to 131/200 (p=.5118).

**Limitations:** Cost savings are conditional on common successes and concern host-model inference, not total system cost. Evidence covers one planner/host and two discrete-action simulations; ALFWorld success differences are not significant. Library growth demonstrates read-time adoption, not monotonic success improvement or continuous robot control.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.32412) · [Reviewed version](https://arxiv.org/abs/2610.32412v1) · [Full text](https://arxiv.org/html/2610.32412v1). No paper-specific public code link was found in the abstract or full text.

### When to Stop Penalizing Actions? Martingale GRPO for VLA Reinforcement Learning

**Metadata:** arXiv 2610.32431v1 · New paper · First submitted 2026-10-23 09:56:27 UTC. Review: Full-text methods, key experiments, and limitations checked; author-reported results, not independently reproduced.

**Contribution:** MART-GRPO uses a fine-tuned, then frozen VLM to locate the last visible unrecovered error in full rollout videos and truncate subsequent failure penalties, retaining successful-rollout terms and original normalization. Ideal stopping results motivate, but do not certify, the retrospective implementation.

**Evidence:** With OpenVLA-OFT on seven RoboTwin 2.0 tasks, matched initial checkpoints and 40 updates, mean success rises from full-GRPO 65.01% to 68.64%. Each task has 128 seen-seed and 128 held-out-seed episodes. On Hammer/Handover, event boundaries outperform uniform penalty scaling by 3.52/3.12 points and random prefixes by 9.38/2.34 points.

**Limitations:** Simulation only. The actor sees one camera while the VLM reviews three; additional annotations and VLM fine-tuning are required. Boundaries use future rollout information and need not satisfy ideal stopping assumptions. One task declines by 1.95 points; held-out scene seeds are not independent training seeds.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.32431) · [Reviewed version](https://arxiv.org/abs/2610.32431v1) · [Full text](https://arxiv.org/html/2610.32431v1). No paper-specific public code link was found in the abstract or full text.

**Metadata:** arXiv 2610.31859v1 · New paper · First submitted 2026-10-22 19:45:06 UTC. Review: Full-text methods, experiments and limitations checked; author-reported results, not reproduced.

**Metadata:** arXiv 2610.32102v1 · New paper · First submitted 2026-10-23 03:07:04 UTC. Review: Full-text methods, experiments and limitations checked; author-reported results, not reproduced.

**Contribution:** Jointly studies executed action horizon and flow-solver depth, testing when shallow sampling helps or harms.

**Metadata:** arXiv 2610.32941v1 · New paper · First submitted 2026-10-23 17:35:33 UTC. Review: Full-text methods, experiments and limitations checked; author-reported results, not reproduced.

### ACWM-RM: A Reference-Free Reward Model from Complementary Mismatch Preferences

**Metadata:** arXiv 2610.32222v1 · New paper · First submitted 2026-10-23 06:27:26 UTC. Review: Full-text methods, key experiments, and limitations checked; author-reported results, not independently reproduced.

**Contribution:** A reward model combines action-mismatch and video-mismatch preferences to judge visual quality and action following without reference videos at reward-computation time. It introduces AVM-Eval (67.2k pairs) and AVM-Pref (506.3k pairs).

**Evidence:** On AgiBot generated-video mismatch pairs, accuracy is 88.6% versus the strongest tested IDM at 70.0%; action-mismatch accuracy is 91.6% versus 86.1%. Flow-GRPO on DreamDojo-2B improves PSNR from 23.13 to 24.34 and FVD from 18.31 to 17.10; physical-consistency rating is 3.93 versus pre-RL 4.00 on a 1–5 scale.

**Limitations:** RL evidence is restricted to one 2B world model and AgiBotWorld, not robot task success. Physical consistency is not directly supervised and ratings rely on a VLM. Reference-free reward computation does not mean reference-free dataset construction; pairwise ranking is not a guarantee of physical validity.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.32222) · [Reviewed version](https://arxiv.org/abs/2610.32222v1) · [Full text](https://arxiv.org/html/2610.32222v1). No paper-specific public code link was found in the abstract or full text.

### UniAction: Unified Action Conditioning for World Models

**Metadata:** arXiv 2610.32977v1 · New paper · First submitted 2026-10-23 17:59:13 UTC. Review: Full-text methods, key experiments, and limitations checked; author-reported results, not independently reproduced.

**Contribution:** UniAction represents force, camera, hand and robot-pose actions as sparse semantic elements with continuous spatiotemporal coordinates, mapped into the video backbone’s native RoPE geometry. Cardinality-calibrated attention compensates for different action-token counts.

**Evidence:** All conditioning baselines use the same pretrained model, 40k clips and optimization settings; 410 counterfactual generations evaluate action following. Robot-pose score is .6521 versus VACE .5245 and cross-attention .0859. Joint training scores .6521 versus a robot-only expert .6310, with matched per-form sample exposure and total compute across four experts.

**Limitations:** These are video-generation action-following scores, not closed-loop robot success. Conditioning branches differ in trainable parameter counts. Joint training does not improve every metric: camera LPIPS is .4863 versus expert .4780. Four specified action forms do not establish arbitrary-action or unseen-embodiment generalization.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.32977) · [Reviewed version](https://arxiv.org/abs/2610.32977v1) · [Full text](https://arxiv.org/html/2610.32977v1) · [Project](https://uniaction.github.io/). ### Ψ-0.6: Adaptive Streams of Thought in a Unified Vision-Language World Model

**Metadata:** arXiv 2610.32177v1 · New paper · First submitted 2026-10-23 05:24:02 UTC. Review: Full-text methods, key experiments, and limitations checked; author-reported results, not independently reproduced.

### WorldMirror: Agentic Real-to-Sim Generation of Interactive Worlds from In-the-Wild Robot Demonstrations

**Metadata:** arXiv 2610.31834v1 · New paper · First submitted 2026-10-22 19:13:05 UTC. Review: Full-text key methods, experiments and limitations checked; not independently reproduced.

**Contribution:** Constructs executable world programs from robot demonstrations, with a coding agent using replay feedback to repair scene geometry, assets, and physical interactions.

### EgoForesight: Effectively Scaling Policy Learning with Noisy Egocentric Actions

**Metadata:** arXiv 2610.31845v1 · New paper · First submitted 2026-10-22 19:28:43 UTC. Review: Full-text key methods, experiments and limitations checked; not independently reproduced.

**Contribution:** Combines reliability-dependent corruption and loss weighting with joint vision–action flow and privileged-future EMA distillation to learn from noisy human action labels.
