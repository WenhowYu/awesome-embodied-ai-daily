## Scaling Online Exploration for Robot Agents

- arXiv: [2610.22496v1](https://arxiv.org/abs/2610.22496v1) · New paper · First submitted: 2026-10-15 UTC
- Review: Selected full-text methods/experiments checked

**Contribution and context.** A frozen coding agent explores through robot APIs and turns perception, planning, and control into executable programs. Persistent notes and validated skills support reuse across episodes and tasks.

**Evidence and limitations.** The paper reports a mean gain of 37.4 points across five simulation benchmarks and demonstrates real manipulation on Franka and RB-Y1. HumanoidArena uses three demonstrations per task, so the results are not uniformly demonstration-free. Cross-robot skill sharing remains future work, rather than established general cross-embodiment transfer.

**Code and materials.** Code and a real-robot skill library were accessible at the archive review; access does not establish reproducibility.

## When Plans Change, Remember: Replanning-Guided Visual Memory for Vision-Language-Action Models

- arXiv: [2610.22556v1](https://arxiv.org/abs/2610.22556v1) · New paper · First submitted: 2026-10-15 UTC
- Review: Selected full-text methods/experiments checked

**Contribution and context.** Disagreement between adjacent action chunks about the same future time supplies a memory-write signal. A bounded visual memory stores key frames and filters duplicates. Memory is cleared at the start of each episode, so this is within-episode memory.

**Evidence and limitations.** For OpenVLA-OFT and π0.5 on MIKASA-Robo-VLA, event-detection ROC-AUC is 0.981–0.997 and tested memory-retention experiments reach 100%. These are not task success rates. Real-robot evidence is offline trajectory replay. Thresholds require task calibration; transfer to unseen tasks is unproven.

**Code and materials.** A project page was available; no verifiable code repository was found.

[Paper v1](https://arxiv.org/abs/2610.22556v1) · [Project](https://vika787.github.io/RePlanMem/)

## Embodiment-Classifier Guidance: Transferring Frozen VLAs Across Robot Dynamics without Demonstrations

- arXiv: [2610.22576v1](https://arxiv.org/abs/2610.22576v1) · New paper · First submitted: 2026-10-15 UTC
- Review: Selected full-text methods/experiments checked

**Contribution and context.** An embodiment classifier is trained using successful rollouts from a small set of calibration tasks. Its gradients guide each π0 denoising step while the VLA stays frozen, connecting test-time action guidance with dynamics adaptation.

**Evidence and limitations.** Across four controller changes and 12 task-suite/controller combinations in LIBERO, average success rises from 72% to 80%; 11 combinations improve and five remain significant after Holm correction. Weak-wrist results are mixed, and locked wrists can degrade. All experiments are simulated and require successful target-robot samples; real-robot zero-shot transfer is not established.

**Code and materials.** No verifiable code link was found.

[Paper v1](https://arxiv.org/abs/2610.22576v1)

## Spatial Memory by Agents, for Agents

- arXiv: [2610.22736v1](https://arxiv.org/abs/2610.22736v1) · New paper · First submitted: 2026-10-15 UTC
- Review: Abstract screening and project-page check; full text not checked

**Contribution and context.** A Designer Agent iterates memory construction and retrieval programs using feedback from a fixed Query Agent, then freezes the implementation for held-out observation histories. The tasks concern spatial/temporal questions, localization, and navigation queries, rather than continual manipulation-skill learning.

**Evidence and limitations.** The abstract reports a five-task mean of 44.23 across three independent design searches versus 29.32 for ReMEmbR, a 50.9% increase. The project page separately lists 45.75 selected using public test scores; these protocols must not be mixed. The full paper was not checked.

**Code and materials.** The project page stated “Code soon” at review time.

## LAW: Unifying Language, Action, and World Modeling for Agentic Physical Intelligence

- arXiv: [2610.23334v1](https://arxiv.org/abs/2610.23334v1) · New paper · First submitted: 2026-10-16 UTC
- Review: Selected full-text methods/experiments checked

**Contribution and context.** Semantic subtask progress connects VLM planning, state assessment, and world-action-model action generation, with hierarchical visual memory and subtask value learning.

**Evidence and limitations.** Average success is 94.21% over 50 RoboTwin tasks. Three long-horizon real-robot tasks, each tested 20 times, average 65% versus 28.33% for π0.5. Each real task uses 300 demonstrations and evaluation freezes model parameters. A memory ablation on RoboDojo Memory changes only 3.44% to 5.44%; overall scores do not establish strong memory capability.

**Code and materials.** No usable official code repository was verified.

[Paper v1](https://arxiv.org/abs/2610.23334v1)

## AnchorQ: Sample-Efficient Reinforcement Learning for Policy Improvement via Flow-Reversed Action Anchors

- arXiv: [2610.22852v1](https://arxiv.org/abs/2610.22852v1) · New paper · First submitted: 2026-10-16 UTC
- Review: Selected full-text methods/experiments checked

**Contribution and context.** Flow reversal maps rough reference actions to state-dependent noise anchors. Local particles and an online critic guide exploration while the base VLA remains frozen.

**Evidence and limitations.** Mean simulation throughput is 294 trials/hour versus 149 for DSRL, a 97% increase. Three real Franka manipulation tasks each use 100 training episodes and 20 unseen test configurations, outperforming two baselines. Human terminal rewards and environment resets remain necessary; multitask continual learning is untested.

**Code and materials.** The project displayed a Code label, but no valid repository link was found.

[Paper v1](https://arxiv.org/abs/2610.22852v1) · [Project](https://anchorq-rl.com/)

## NestedVLA: Learning to Consolidate and Generate Skills for Vision-Language-Action Models

- arXiv: [2610.23271v1](https://arxiv.org/abs/2610.23271v1) · New paper · First submitted: 2026-10-16 UTC
- Review: Selected full-text methods/experiments checked

**Contribution and context.** Skills are trained separately and then a task-conditioned hypernetwork generates action-expert parameters, reducing conflicts from directly merging weights. This is a parameterized skill-consolidation approach.

**Evidence and limitations.** Mean success across three simulation benchmarks is 66.7%, versus 25.6% for the strongest merging baseline. Storage is about 1.5 times one model, versus three times for retaining three models. Only three benchmark-level skills are studied. Adding skills still requires expanding and retraining the hypernetwork; there is no real-robot validation or established online continual learning.

**Code and materials.** The accessible repository contained the core algorithm, but not datasets, simulators, checkpoints, or experiment launch configurations.

[Paper v1](https://arxiv.org/abs/2610.23271v1) · [Repository](https://github.com/WanyuGroup/NeurIPS2026-NestedVLA)

## ORD-WM: Learning Object-Centric Rigid Dynamics for 3D World Modeling in Robotic Manipulation

- arXiv: [2610.23156v1](https://arxiv.org/abs/2610.23156v1) · New paper · First submitted: 2026-10-16 UTC
- Review: Selected full-text methods/experiments checked

**Contribution and context.** Rotation-equivariant latents encode object shape; predicted SE(3) transformations are applied analytically to preserve rigid geometry over multistep world-model rollouts.

**Evidence and limitations.** Real pushing with 1,024 candidate trajectories achieves 90% success and a mean final-position error of 0.972 cm; replanning takes 269.9 ms on an RTX 3090. Success means error below 2 cm. The scope is low-dynamic rigid objects, excluding direct treatment of articulated or deformable objects. Shape preservation does not guarantee correct contact physics or prevent interpenetration.

**Code and materials.** The project Code link returned to the same page; no valid implementation repository was verified.

## Beyond Success Rate: Interventional Evaluation of Memory in Vision-Language-Action Systems

- arXiv: [2610.23372v1](https://arxiv.org/abs/2610.23372v1) · New paper · First submitted: 2026-10-16 UTC
- Review: Selected full-text methods/experiments checked

**Contribution and context.** Key-fact replacement, fact-preserving replacement, and numerical perturbation controls test whether robot systems causally use memory content, separating memory effects from general system sensitivity.

**Evidence and limitations.** In cross-episode experiments, tiny perturbations already alter 11.9% of paired outcomes; replacing key facts shows no clear additional effect. On 202 ChainBench chains, full memory raises success from 39.1% to 74.3%. All experiments are simulated, and the latter uses curated records and shared-record execution. This does not establish an independent real-robot closed-loop memory system.

**Code and materials.** The paper linked anonymous supplementary materials; access was not verified.

[Paper v1](https://arxiv.org/abs/2610.23372v1)
