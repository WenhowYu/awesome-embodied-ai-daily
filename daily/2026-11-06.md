### Fast and Reliable Open-Vocabulary Object Search with Absence Detection from Robot Memory

**Metadata:** arXiv 2611.07493v1 · New paper · First submitted 2026-11-05T05:57:32Z. Review: Official abstract plus selected full-text method, evaluation and caveat passages inspected; author-reported, not independently reproduced.

**Contribution:** Retrieval followed by visual verification lets robot memory abstain when an object is absent.

**Evidence:** Eight ScanNet apartments × 100 queries (30% absent): specificity up to 92.5% vs at most 9% without visual verification. Reported query time <2 s vs ~5 min exhaustive search over 1,000 frames.

**Limitations:** Specificity and recall trade off; complex attribute queries challenge SAM3. Caption preprocessing is slow (0.1 Hz). Real test has only 36 queries.

### Which Objects Stay? Learning Hierarchical Persistence Beliefs for Lifelong Open-Vocabulary Object Maps

**Metadata:** arXiv 2611.07662v1 · New paper · First submitted 2026-11-05T08:45:45Z. Review: Selected full-text check: experimental protocol, THOR/3RScan results, conclusion; README

**Contribution:** HiPer retrieves appearance/geometry-based persistence priors, updates object-specific Bayesian survival beliefs, and transfers those beliefs when objects relocate.

**Evidence:** 120 held-out THOR sequences: NLL 0.265 and AUROC 0.911. On 47 held-out 3RScan environments: NLL 0.310 and AUROC 0.790. The real-data benefit is mainly retrieval priors, not demonstrated gains from object-specific online learning.

**Limitations:** Uses oracle segmentation and within-session tracking. 3RScan rescans are treated as one day apart; sparse revisits limit lifelong-learning evidence. ObChange influenced development and is weaker confirmatory evidence; no end-to-end autonomous deployment shown.

**Resources checked:** Repository/README accessible with implementation paths, tests and evaluation commands. Data downloads and code execution were not performed; README ROS integration is labeled experimental.
