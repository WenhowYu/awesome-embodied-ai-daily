## Scope and reading notes

This archive covers the **2026-10-21 announcement batch**: **14 new papers, 3 substantive or numerical revisions, and 1 supplemental review of PrismWAM from the 2026-10-20 batch**. The archive date is an announcement-batch date, not necessarily a submission date. Initial-submission and revision dates below are UTC.

The review screened cs.RO new submissions, cross-lists, and revisions, with cross-checks in cs.AI, cs.LG, and cs.CV. Entries were deduplicated by version-independent arXiv ID and previous archive coverage. The 2026-10-21 batch corresponds to Tuesday evening in US Eastern time and Wednesday in Beijing. October 20 was not an official no-announcement day. The batch was confirmed as released even though some live “new” pages initially served old cached content; those pages alone could not establish a delay or absence of new papers.

**All experimental numbers are author-reported, not independently reproduced.** Review depth is stated for each entry and should not be read as more extensive than indicated. Project and code statuses describe the checks recorded for this archive. An accessible repository does not establish reproducibility, and unexecuted materials remain explicitly qualified. The cross-category coverage limitation recorded for October 19 still applies; this archive does not retroactively claim complete historical coverage.

## Experience internalization, working memory, and execution state

<a id="arxiv-2610.28589"></a>
### AgenticRoboRL: Bringing Coding-Agent Post-Training to Agentic Robotics

- **Metadata:** arXiv 2610.28589v1 · New paper · Initial submission: 2026-10-20
- **Review depth:** Main-text experiments and ablations checked.

**Contribution / update:** Successful-trajectory supervised fine-tuning (SFT), followed by multi-turn reinforcement learning (RL), trains a 9B planner for RPent VLA calls and CaP-X code execution. The method internalizes experience in planner parameters while keeping the executor frozen; it changes more than the granularity of skill calls.

**Evidence and limitations:** Across 800 LIBERO-PRO episodes, performance rises from 18.1% to 65.1% after SFT and 71.0% after RL; memory-enabled Codex reaches 72.1% and Claude Code 82.4%. CaP-X is trained separately and uses privileged state, so this is not zero-shot transfer between harnesses. There is no external memory at test time, but the teacher uses task and global memory. Training and testing share tasks and separate only initial states. No real-robot evidence is provided, and the results do not establish continual online skill expansion.

**Resources:**
- [arXiv record](https://arxiv.org/abs/2610.28589) · [Reviewed version v1](https://arxiv.org/abs/2610.28589v1)
- [Code repository](https://github.com/L-CodingSpace/AgenticRoboRL): The official repository named in the paper returned 404 at review time; framework and weights remained planned releases.

<a id="arxiv-2610.28626"></a>
### UniWALM: Unified World Action Language Model for Embodied Robot Control

- **Metadata:** arXiv 2610.28626v1 · New paper · Initial submission: 2026-10-20
- **Review depth:** Main text and ablations checked.

**Contribution / update:** Video, actions, and language are denoised together in a single MoT. Generated subtasks and textual working memory feed into the next step, while FMC trains action correction. This integrates working memory into the world-action-language model.

**Evidence and limitations:** On four RMBench memory tasks, UniWALM achieves 34.5%, versus FastWAM at 13.3% and Mem-0 at 28.5%; WLA-0 is higher at 56.5%. In 18 real-robot object-search trials it achieves 61.1%, versus FastWAM at 11.1%. The sample is small, and the total improvement combines language, FMC, and LoRA, so it cannot all be attributed to memory. Only within-episode working memory is demonstrated; cross-episode retrieval is future work, and OpenWAM is not evaluated.

**Resources:**
- [arXiv record](https://arxiv.org/abs/2610.28626) · [Reviewed version v1](https://arxiv.org/abs/2610.28626v1)
- [Project](https://rahulsajnani.github.io/projects/uniwalm/): Accessible at review time; no code-repository link was found.

<a id="arxiv-2610.27917"></a>
### EventSync: Event-Driven Memory Updates for History-Dependent Manipulation

- **Metadata:** arXiv 2610.27917v1 · New paper · Initial submission: 2026-10-20
- **Review depth:** Main text and appendix checked.

**Contribution / update:** Qwen3-VL-4B reasons over subgoals and π0.5 executes them. An event monitor fuses images and end-effector trajectories, committing history and triggering the next step only after completion is confirmed. This makes task-progress memory updates evidence-gated.

**Evidence and limitations:** RoboMME success is 64.5%, with 70.8% fewer high-level calls than fixed stepwise reasoning. Removing high-level visual history reduces success to 54.5%. Four real-robot tasks use 10 trials each, with 9/7/9/7 successes. The main leaderboard reuses published benchmark baselines rather than rerunning all methods under one setup. The monitor needs event labels and additional training; cross-episode skill accumulation is not demonstrated.

**Resources:**
- [arXiv record](https://arxiv.org/abs/2610.27917) · [Reviewed version v1](https://arxiv.org/abs/2610.27917v1)
- [Project](https://zjjjacinthe.github.io/eventsync-project/): Retrieval failed during review; code availability was not verified.

<a id="arxiv-2610.28431"></a>
### Plausible Future, Wrong Choice: Steering World-Action Models toward Intended Future

- **Metadata:** arXiv 2610.28431v1 · New paper · Initial submission: 2026-10-20
- **Review depth:** Main tables, ablations, and real-robot protocol checked.

**Contribution / update:** TaskWAM uses Mode Tokens to encode task requirements and State Tokens to track causal execution history. Together they steer predicted futures and actions, addressing stage confusion caused by visually similar observations.

**Evidence and limitations:** Under a same-data StageBench evaluation, FastWAM rises from 40.9% to 69.4%. Adding Mode Tokens, State Tokens, and residual guidance yields 56.4%, 61.6%, and 69.4%, respectively. Final-stage performance on four real-robot tasks improves by 15–35 percentage points, but each task requires 100–150 demonstrations and each variant has only 10–20 trials. Deployment on multiple embodiments does not establish data-free transfer. The long-horizon toast task still has only 20% success.

**Resources:**
- [arXiv record](https://arxiv.org/abs/2610.28431) · [Reviewed version v1](https://arxiv.org/abs/2610.28431v1)
- [Project](https://isee-laboratory.github.io/TaskWAM/): Accessible at review time; no usable code link was found.

## World models and low-latency control

<a id="arxiv-2610.28613"></a>
### Physical Canvas: A Vision Tactile World Model For Robot Policy Evaluation And Learning

- **Metadata:** arXiv 2610.28613v1 · New paper · Initial submission: 2026-10-20
- **Review depth:** Main-text and appendix experiments checked.

**Contribution / update:** PhysCanvas combines RGB, tactile signals, displacement, and task state into a canvas. Action projections condition a video model, and scene, modality, and state rewards improve consistency. The model supports policy evaluation, imagined interaction, and π0.5 post-training.

**Evidence and limitations:** Across four ARX dual-arm tasks, the mean of the within-task correlations between world-model and real-world success rates improves from 0.602 to 0.885. For tactile-augmented π0.5, model-based GRPO increases mean real-robot success from the SFT baseline of 59.1% to 67.5%; using the consistency-post-trained world model raises it further to 70.8%. The bottle-cap task is lower than SFT (86.6% versus 88.3%). Evidence covers one hardware platform and four tasks, not generic π0.5 performance or cross-sensor generalization.

**Resources:**
- [arXiv record](https://arxiv.org/abs/2610.28613) · [Reviewed version v1](https://arxiv.org/abs/2610.28613v1)
- [Project](https://zebinx.github.io/PhysCanvas_HomePage/): Code and model were marked “Coming Soon.”

<a id="arxiv-2610.28122"></a>
### De-Diffusing WAMs: Action-Sufficient Direct Prediction for Robot Control

- **Metadata:** arXiv 2610.28122v1 · New paper · Initial submission: 2026-10-20
- **Review depth:** Main text and appendix checked.

**Contribution / update:** DirectWAM builds on LingBot-VA, freezing a one-step action expert and backpropagating demonstration-action error into a future predictor. It preserves the future-to-action cascade while supervising the future representation by its action consequences. No OpenWAM experiment is reported.

**Evidence and limitations:** Success is 97.1% on LIBERO and 85.4% on RoboTwin. On RoboTwin it exceeds Flash-WAM at the same 1/1-step configuration (78.2%) but remains below the full teacher (90.7%). The reported 28× speedup is model-side. The LIBERO Flash-WAM number is taken from its original paper, not reproduced from the same checkpoint. Three real-robot tasks use 20 trials each, with 19/11/12 successes versus the teacher’s 19/9/12; this does not establish general superiority over the teacher.

**Resources:**
- [arXiv record](https://arxiv.org/abs/2610.28122) · [Reviewed version v1](https://arxiv.org/abs/2610.28122v1)
- The official abstract and full text provide no code or project link; public code was not confirmed.

<a id="arxiv-2610.28019"></a>
### PACT-VLA: Speculative Action-Chunk Verification with Pre-Commit Observations

- **Metadata:** arXiv 2610.28019v1 · New paper · Initial submission: 2026-10-20
- **Review depth:** Main text and appendix checked.

**Contribution / update:** PACT-VLA generates candidate action chunks from an older observation, scores them with a frozen flow policy using a newer pre-commit observation, and selects one complete chunk. It provides a pre-commit verification mechanism for asynchronous control. FlowRes is neither a success probability nor a safety guarantee.

**Evidence and limitations:** Across three real-robot tasks with 50 trials each, success with the same frozen π0.5 increases from 60% to 82%. With GR00T and eight candidates in both conditions, scoring with a newer observation reaches 56.4%, versus 52.6% with the old observation; however, complete rollouts do not share candidate pools. Mean performance drops slightly at one-step delay, and confidence intervals are not reported. Zero additional control steps still incur computation: P99 latency on a 5090 rises from 35.4 to 60.2 ms.

**Resources:**
- [arXiv record](https://arxiv.org/abs/2610.28019) · [Reviewed version v1](https://arxiv.org/abs/2610.28019v1)
- The official abstract and full text provide no code or project link; public code was not confirmed.

<a id="arxiv-2610.27387"></a>
### Training Controllable World Models via Action Influence Maximization

- **Metadata:** arXiv 2610.27387v1 · New paper · Initial submission: 2026-10-19
- **Review depth:** Main-text methods, experiments, and limitations checked.

**Contribution / update:** Action Influence Maximization (AIM) guides batched online-RL data collection toward interactions that reveal action consequences. It addresses narrow successful-demonstration distributions and world models that ignore actions.

**Evidence and limitations:** Comparisons use the same architecture and training setup with matched rollout budgets. On Push-T, 3,000 demonstrations plus 500 active episodes match 300,000 demonstrations on terminal controllability in behavior-cloning (BC) rollouts. The 85× figure is a data-volume ratio for that metric, not manipulation success or general speedup. Evaluation is limited to Four Rooms and Push-T simulation. Retraining multiple density-based reward models is expensive, and some ablations outperform the full AIM method.

**Resources:**
- [arXiv record](https://arxiv.org/abs/2610.27387) · [Reviewed version v1](https://arxiv.org/abs/2610.27387v1)
- [Code repository](https://github.com/princeton-prism/action-influence-maximization): Accessible at review time, but contained only a README and project materials marked “coming soon”; algorithm code was not yet available.

## Offline improvement and memory diagnostics

<a id="arxiv-2610.27736"></a>
### AWLS: Advantage-Weighted Latent Steering for One-Step Generative Robotic Manipulation Policies

- **Metadata:** arXiv 2610.27736v1 · New paper · Initial submission: 2026-10-20
- **Review depth:** Project-hosted full paper and real-robot statistics checked.

**Contribution / update:** AWLS trains only a residual noise-shaping module, using IQL advantages to weight demonstration reconstruction while freezing a one-step decoder. This is a conservative offline improvement approach for mixed-quality experience.

**Evidence and limitations:** Each of five real-robot tasks uses 70 demonstrations and 20 trials, with zero real-robot rollouts during post-training. AWLS achieves 65/100 successes, versus MeanFlow at 45/100, FQL at 51/100, and DSRL at 50/100. After multiple-comparison correction, only the aggregate improvement over MeanFlow is significant. The method strengthens behaviors already present in demonstrations and reachable by the decoder; it does not discover new skills and still depends on critic ranking.

**Resources:**
- [arXiv record](https://arxiv.org/abs/2610.27736) · [Reviewed version v1](https://arxiv.org/abs/2610.27736v1)
- [Project](https://awls-corl2026.github.io/): Paper and videos were accessible; no code link was found.

<a id="arxiv-2610.27714"></a>
### When Does Experience Memory Help Closed-Loop LLM Driving Agents? A Controlled Evaluation with Resampled Warmup Pools, Token-Matched Fillers, and Audited Baselines

- **Metadata:** arXiv 2610.27714v1 · New paper · Initial submission: 2026-10-20
- **Review depth:** Official PDF full text checked.

**Contribution / update:** The study treats warmup experience pools as a random factor and adds token-matched irrelevant text, fixed rules, history-only, and oracle controls. Its driving-simulation design supplies controlled tests of retrieval-based experience memory.

**Evidence and limitations:** Across 10 disjoint experience pools, each of two retrieval-memory methods outperforms no memory in only one pool. In a representative pool, token-matched filler reaches 80%, versus retrieval at 67% and 66%. A safety advantage disappears after accounting for progress efficiency. The decisive findings are limited to HighwayEnv, gpt-4o-mini, and a 1 Hz control rate. The RESPOND-inspired port fails an audit and does not represent the original system. These results do not support a blanket claim that all memory is ineffective.

**Resources:**
- [arXiv record](https://arxiv.org/abs/2610.27714) · [Reviewed version v1](https://arxiv.org/abs/2610.27714v1)
- The paper states that materials are released, but a verifiable author repository could not be located during review.

## Cross-category papers: retention and procedural memory

<a id="arxiv-2610.27698"></a>
### VLA-Retain: Benchmarking Cross-Dimension Effects of Vision Tuning in VLAs

- **Metadata:** arXiv 2610.27698v1 · New paper · Initial submission: 2026-10-20
- **Review depth:** Focused main-text review.

**Contribution / update:** VLA-Retain pairs five VLAs with their vision-tuned checkpoints across seven LIBERO-Plus perturbation categories and 10,030 evaluation episodes. It measures target-domain gains alongside retention on untargeted dimensions.

**Evidence and limitations:** In 8 of 10 model–domain settings, the mean non-target change is negative. X-VLA camera adaptation gives +69.4 percentage points on the target and −4.6 points off target. DELTA-style protection helps X-VLA but lowers OpenVLA-OFT non-target retention by 23.1 points. The controlled intervention is targeted fine-tuning, not online continual deployment or test-time training itself.

**Resources:**
- [arXiv record](https://arxiv.org/abs/2610.27698) · [Reviewed version v1](https://arxiv.org/abs/2610.27698v1)
- [Code repository](https://github.com/BoruiXu/VLA_vision_tuning_benchmark): The repository is linked in the paper; reproducibility was not verified during review.

### LaLa-World: Scaling Latent World Models with Natural Language Actions

- **Metadata:** arXiv 2610.27851v1 · New paper · Initial submission: 2026-10-20
- **Review depth:** Focused review of main-text tables.

**Contribution / update:** LaLa-World converts numerical actions and visual changes into natural-language actions for latent future prediction from heterogeneous data. LaLa-Policy then predicts actions and visual futures jointly. The paper lacks a cs.RO tag but directly concerns world-action-model pretraining and transfer to control.

**Evidence and limitations:** LIBERO success is 97.7%, versus Cosmos Policy at 97.3%; mean LIBERO inference time per trajectory is 0.86 versus 4.45 seconds. Planning-speed and policy-inference-speed measurements must be kept separate. DROID metrics score action prediction rather than real-robot success, and the method does not win on every planning domain.

- [arXiv record](https://arxiv.org/abs/2610.27851) · [Reviewed version v1](https://arxiv.org/abs/2610.27851v1)

<a id="arxiv-2610.26995"></a>
### SPEM: Structure-Aware Procedural Memory for Efficient Skill Use in LLM Agents

- **Metadata:** arXiv 2610.26995v1 · New paper · Initial submission: 2026-10-19
- **Review depth:** Focused main-text review.

**Contribution / update:** SPEM stores successful skill compositions as Skill-DAGs and uses a Skill-GNN to choose them by state. It organizes and reuses the structure of procedural experience across tasks.

**Evidence and limitations:** ALFWorld success is 87.1%, versus SkillDAG at 85.7%, while runtime drops from 169.10 to 66.01 seconds. SkillsBench reward is 38.38, versus GoS at 37.50. The latter covers only 67 tasks selected through shared-infrastructure filtering. The method mainly composes existing skills rather than autonomously acquiring new motor skills; there is no real-robot evidence.

**Resources:**

<a id="arxiv-2610.27406"></a>
### More Memory, Worse Agents: Error Reproduction and Anti-Persistence in LLM Agents

- **Metadata:** arXiv 2610.27406v1 · New paper · Initial submission: 2026-10-19
- **Review depth:** Focused review of controlled main-text experiments.

**Contribution / update:** The method keeps raw trajectories and outcomes, rebuilding and discarding task-specific abstractions on each use. This aims to prevent erroneous rules from propagating through repeated execution and re-abstraction.

**Evidence and limitations:** Matched persist/discard ablations over three seeds increase Llama-4-Scout ALFWorld success from 26.7% to 54.7%, and Qwen3-Coder-Next from 92.7% to 96.0%. These are counterexamples to persistent abstractions for particular agents and tasks; they do not show that all long-term procedural memory is harmful. Robotic execution is not evaluated.

**Resources:**
- [arXiv record](https://arxiv.org/abs/2610.27406) · [Reviewed version v1](https://arxiv.org/abs/2610.27406v1)
- No usable official code or project link was verified during review.

### HexaShell: A Thin Harness for Exploring the Limits of VLM Agents as Robot Coding Agents

- **Metadata:** arXiv 2610.23479v2 · Substantive revision · Initial submission: 2026-10-16 · v2: 2026-10-20
- **Review depth:** Full-text v1/v2 comparison.

**Contribution / update:** HexaShell turns failure experience into executable tools. The revision adds RoboDojo official hidden-seed evaluation with 50 episodes for each of 42 tasks; eight Open tasks share tools, testing tool reuse and evaluation isolation.

**Evidence and limitations:** The revised success rate is 46.9%, progress is 53.2, and Open success is 55.3%. The old 39.7% result used held-out layouts with the same seed, so the difference cannot be described as a 7.2-point gain under the same protocol. Real-robot evidence consists of only two cross-arm demonstrations, not a systematic success-rate evaluation. Memory is 81% and Precision 32%, indicating continued weakness in contact control. Released materials cover frozen tools and interfaces, not the complete harness, optimizer notes, or tests.

### DEFLECT: Temporal Counterfactual Preference Learning for Delay-Robust Asynchronous VLAs

- **Metadata:** arXiv 2605.19294v3 · Substantive revision · Initial submission: 2026-05-19 · v3: 2026-10-20
- **Review depth:** v2/v3 comparison and latest PDF checked.

**Contribution / update:** DEFLECT generates preference supervision offline from future observations while keeping deployment inputs unchanged. The revision adds SmolVLA, GR00T N1.7, Continued SFT, and Future SFT comparisons. Unlike online pre-commit verification, its future-observation signal is used during training.

**Evidence and limitations:** At four-step delay, GR00T reaches 73.10% success, versus naive asynchronous control at 50.40% and Future SFT at 65.75%. Delay, training-step counts, and protocols change across versions, so headline numbers cannot be used as a longitudinal improvement claim. Results on the three real-robot tasks are unchanged. No verifiable code or project link was found.

### WorldScape Policy 2.0: Empowering Steerable World Action Modeling with Reasoning-Augmented Memory and In-Context Learning

- **Metadata:** arXiv 2607.18840v3 · Numerical revision · Initial submission: 2026-07-21 · v3: 2026-10-20
- **Review depth:** v2/v3 tables and main text compared.

**Contribution / update:** This is a numerical revision, not a newly introduced architecture or dataset. ### PrismWAM: Decoupling State Representations in World Action Models

- **Metadata:** arXiv 2610.26564v1 · Supplemental review of the 2026-10-20 announcement; not new in this batch · Initial submission: 2026-10-19
- **Review depth:** Main text and project checked.

**Contribution / update:** PrismWAM factors control into RGB semantic goals → depth futures → actions. Chained attention blocks the action branch from reading RGB directly, separating semantic goals from depth-based physical prediction.

**Evidence and limitations:** Base-model RoboTwin C2R success is 70.57%, versus OpenWAM-α at 69.05%. The 15B model reaches 83.67% with additional video pretraining and is not an equal-budget comparison. Pooled real-robot OOD success is 24/35 versus 17/35 across only three tasks. LIBERO-Plus and LIBERO-Pro scores remain below π0.5. Real deployment uses RGB-D and depth refinement, not RGB-only input.

**Resources:**
- [arXiv record](https://arxiv.org/abs/2610.26564) · [Reviewed version v1](https://arxiv.org/abs/2610.26564v1)
- [Project](https://prism-wam.github.io/)
