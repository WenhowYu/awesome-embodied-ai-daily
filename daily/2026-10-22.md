## Robot agents and experience memory


<a id="arxiv-2610.29329"></a>

### Plan First, Act Later: Streaming Reasoning for Executable Memory in Robot Control

**Metadata:** arXiv 2610.29329v1 · New paper · First submitted 2026-10-21 UTC. Review: Full-text experiments and ablations checked.

**Contribution:** PAL organizes memory into short-term visual observations, semantic events, and an executable subtask_list. It writes future subtasks when supporting evidence appears and activates them at execution time. Its comparison with Astra+VLA examines the interface between memory and robot control.

**Evidence and limitations:** RoboMME success is 56.05 ± 1.38%, versus FrameSamp 44.51%, MemER 42.38%, and Astra+VLA 39.75%. On four real-robot tasks, with 30 trials per task, PAL reports 60.83% versus MemER's 45%. Training uses task rules and oracle event labels from simulation. Astra was evaluated with only 1 seed, versus PAL's 5 seeds, and frame sampling differs. Memory is confined to an episode; InsertPeg and StopCube remain at 4.8% and 5.2%. The results do not establish cross-task skill expansion.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.29329) · [v1 abstract](https://arxiv.org/abs/2610.29329v1) · [Full text](https://arxiv.org/html/2610.29329v1) · [Project](https://qinghangliu.github.io/pal-webpage/) · [Author code link (404 at check)](https://github.com/QinghangLiu/PAL_official/tree/main). The author-provided code link returned 404 at the batch check; project videos were accessible.


<a id="arxiv-2610.29560"></a>

### From VLM Planners to Robotic Agents: Self-Evolving Harnesses for History-Dependent Manipulation

**Metadata:** arXiv 2610.29560v1 · New paper · First submitted 2026-10-21 UTC. Review: Full text and development procedure checked.

**Contribution:** SERA freezes the VLA while a high-level agent diagnoses failures in development rollouts and revises planning guidance, evaluation rules, and control configuration. The revised harness is then frozen for testing. This is a system-level adaptation approach related to ASPIRE and CaP-X.

**Evidence and limitations:** Across 16 RoboMME tasks with 50 trials each, success rises from 44.38% to 51.38%. The authors' local MemER reproduction reaches 45.38%, distinct from the leaderboard's 42.38%. Runtime context resets every episode; what persists across episodes is the offline harness revision. The PatternLock fix exposes a previously omitted, already-existing directional command rather than discovering a new skill. Some candidates were selected using a development fallback. There is no systematic quantitative real-robot evaluation.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.29560) · [v1 abstract](https://arxiv.org/abs/2610.29560v1) · [Full text](https://arxiv.org/html/2610.29560v1). No official code or project link was found in the review.


<a id="arxiv-2610.29702"></a>

### CausGround: Causal Interaction Grounding for Adaptive Embodied Planning

**Metadata:** arXiv 2610.29702v1 · New paper · First submitted 2026-10-21 UTC. Review: Full-text evaluation protocol and ablations checked.

**Contribution:** CausGround organizes interaction experience into action preconditions and effects plus object relations. It retrieves dependencies backward from a goal and checks executability against current observations. The planner's parameters remain unchanged.

**Evidence and limitations:** VirtualHome performance rises from 24.9% to 53.3%, and RoboCasa from 43% to 57%. The RoboCasa evaluation is high-level planning along official trajectory replays; UNKNOWN cases involving uncovered branches are excluded from all compared methods. These figures are not low-level robot success rates. The knowledge base is environment-specific, built offline, and not expanded at runtime. Real-robot evidence consists of two qualitative demonstrations without trial counts or success rates. The strength of causal evidence varies across data sources.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.29702) · [v1 abstract](https://arxiv.org/abs/2610.29702v1) · [Full text](https://arxiv.org/html/2610.29702v1) · [Project](https://causground.github.io/). The project page's Code control was disabled and marked coming soon; an implementation was not available for verification.


<a id="arxiv-2610.30105"></a>

### Asymmetric On-Policy Distillation Learns In-Context Exploration

**Metadata:** arXiv 2610.30105v1 · New paper · First submitted 2026-10-21 UTC. Review: Full text and real-robot figures/tables checked.

**Contribution:** ASTEROID collects student histories in partially observed environments, supervises them with a privileged expert, and progressively lengthens context. The student learns to rule out failed hypotheses and reuse information, with evidence for adaptation across episodes sharing the same hidden variable.

**Evidence and limitations:** Real-robot blind grasping achieves 6/10 successes versus behavior cloning's 2/10, a very small sample. Wrist-camera peg insertion reaches approximately 78%, versus approximately 50% for an Opus 5.5 code policy. Ablations support on-policy context and a gradually extended horizon, but the method relies on a strong privileged expert and does not resolve safe exploration. Deployment begins with empty context and uses a sliding window for long runs; this is not a permanent cross-task skill library.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.30105) · [v1 abstract](https://arxiv.org/abs/2610.30105v1) · [Full text](https://arxiv.org/html/2610.30105v1) · [Project](https://weirdlabuw.github.io/asteroid/) · [Code](https://github.com/WEIRDLabUW/asteroid). The repository contains an implementation; completeness of the code for every robot experiment was not verified.


<a id="arxiv-2610.28882"></a>

### inr2action: Encoding Robot Episodes as Neural Implicit Representations for Recall and Action

**Metadata:** arXiv 2610.28882v1 · New paper · First submitted 2026-10-20 UTC. Review: Full-text experiments and limitations checked.

**Contribution:** inr2action fits each episode's video into an implicit neural representation (INR) weight delta, then maps it to 56 tokens for question answering and action readout. The parameter count per memory does not grow with episode duration.

**Evidence and limitations:** RoboMME simulation question-answering accuracy is 47.2 ± 2.6%, versus chance at 34.6% and matched noise at 35.9%. Action R² of 0.51 measures offline command regression, not closed-loop success. Each memory requires 500 fitting steps; training uses 2 seeds. There is no external VLM baseline that reads frames directly, and real-time updates, multi-episode retrieval, and cross-task reuse are not validated.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.28882) · [v1 abstract](https://arxiv.org/abs/2610.28882v1) · [Full text](https://arxiv.org/html/2610.28882v1). No official code or project link was found in the review.


<a id="arxiv-2610.30051"></a>

### From Reasoning to Action: Benchmarking Frontier AI Models on LIBERO-10 Robot Manipulation Tasks

**Metadata:** arXiv 2610.30051v1 · New paper · First submitted 2026-10-21 UTC. Review: Full-text protocol and results checked.

**Contribution:** This benchmark evaluates 6 frontier models at 3 reasoning-effort levels across 1,800 simulated episodes. Models control end-effector poses and the gripper through tool calls, without pretrained manipulation skills or task-specific fine-tuning.

**Evidence and limitations:** At high effort, Astra succeeds in 44/100 trials and Argon in 43/100; a 1-point difference is not a reliable ranking. Astra improves from 28% at low effort to 44% at high effort. Episodes allow at most 80 calls or 900 simulation steps. Failure reflections are logged but not fed back, so the study does not validate gains from accumulated experience. Its tasks and control interface differ from PAL's Astra+VLA setup, preventing direct score comparison.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.30051) · [v1 abstract](https://arxiv.org/abs/2610.30051v1) · [Full text](https://arxiv.org/html/2610.30051v1) · [Project](https://irvlutd.github.io/LLM-LIBERO/) · [Code](https://github.com/IRVLUTD/LLM_LIBERO). The project and code were verified accessible at the batch check. The code was not run in this review.

## World action models and geometric or tactile representations


<a id="arxiv-2610.30136"></a>

### Agentic World Action Models

**Metadata:** arXiv 2610.30136v1 · New paper · First submitted 2026-10-21 UTC. Review: Full text and appendix checked.

**Contribution:** Agentic World Action Models jointly denoise code, future video, and actions. A code-to-video-to-action attention structure connects planning and control, combining code-level agent planning with a world action model.

**Evidence and limitations:** Average RoboTwin success is 50.7%, versus π0.5 at 41.3%; in the random domain, however, it scores 20.6%, below π0.5's 27.7%. The real-robot mean of 71.1 across 8 tasks is a partial-completion score, not whole-task success; DreamZero scores 46.0 and π0.5 43.6. The setup uses 100 demonstrations per task and 3 seeds × 16 evaluations. Downstream data are matched, but pretraining differs. Joint denoising outperforms autoregressive generation, which scores 54.5. The skill library is distilled offline and frozen, while code memory resets each episode; the results do not demonstrate continual skill expansion.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.30136) · [v1 abstract](https://arxiv.org/abs/2610.30136v1) · [Full text](https://arxiv.org/html/2610.30136v1) · [Project](https://agentic-wam.github.io/) · [Code](https://github.com/ZhuoyangLiu2005/agentic-wam) · [Weights](https://huggingface.co/miniFranka/agentic-wam-pretrain-yamego3k-soup-e1/tree/main). Code and 9.96 GB of pretrained weights were verified available. The pretraining corpus and initial Cosmos weights were not released with the repository. The implementation was not run in this review.


<a id="arxiv-2610.30125"></a>

### PhysiCalWorld: In-Context Physics Calibration for World Models

**Metadata:** arXiv 2610.30125v1 · New paper · First submitted 2026-10-21 UTC. Review: Full-text Tables 1–3 and appendix checked.

**Contribution:** PhysiCalWorld compresses 12 frames of exploratory interaction into a 64-dimensional physics descriptor token that conditions DINO-WM or LeWM. It calibrates predictions without test-time gradient updates. Integration with π0.5 was not demonstrated.

**Evidence and limitations:** Each of 4 simulated environments has 75 planning tasks. With DINO-WM, BeerPong rises from 44% to 80% and FetchSlide from 26.7% to 56%. However, the raw-context-prefix baseline reaches 82.7% on BeerPong, and supervised physics estimation is stronger on some tasks. Some long-history baselines use fewer epochs to match GPU hours. There are no real-robot experiments. Training requires groups with shared physics configurations, and cached descriptors are reusable only while physics remains unchanged; this is not cross-task long-term memory.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.30125) · [v1 abstract](https://arxiv.org/abs/2610.30125v1) · [Full text](https://arxiv.org/html/2610.30125v1) · [Project](https://physical-world.github.io/). The project page's Code button was disabled; no released algorithm implementation could be verified.


<a id="arxiv-2610.30117"></a>

### CW-WAM: A Structured Contact-Wrench World Action Model for Force-Sensitive Manipulation

**Metadata:** arXiv 2610.30117v1 · New paper · First submitted 2026-10-21 UTC. Review: Full-text Table II and ablations checked.

**Contribution:** CW-WAM jointly predicts video, actions, and six-dimensional contact wrench. Paired causal attention and a 10-second force history drive a 20 Hz admittance reference for force-sensitive manipulation.

**Evidence and limitations:** The Franka setup uses 450 demonstrations across 4 tasks and 20 evaluations per contact task. Square-peg insertion improves from 25% to 70%, and adapter insertion from 40% to 95%. Ablations with matched data, initialization, and 50k training steps support the role of force history. Admittance reduces force-tracking error without increasing success. Tests stay near the demonstration distribution, control gains are hand-set, and adapter contact forces are also larger, so improved safety cannot be inferred. The 10-second history is not cross-episode memory.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.30117) · [v1 abstract](https://arxiv.org/abs/2610.30117v1) · [Full text](https://arxiv.org/html/2610.30117v1) · [Project](https://cw-wam-project.github.io/). The project page's Code button was disabled at the batch check.


<a id="arxiv-2610.29866"></a>

### GeoMem-VLA: Internalizing 3D Scene Understanding into Temporal Memory for Vision-Language-Action Models

**Metadata:** arXiv 2610.29866v1 · New paper · First submitted 2026-10-21 UTC. Review: Full text and ablations checked.

**Contribution:** GeoMem-VLA uses VGGT only during training to supervise geometry-plan tokens with point maps and end-effector trajectories. Causal retrieval fuses geometry with observation memory; the geometry teacher is removed at inference.

**Evidence and limitations:** On the same backbone, LIBERO success is 98.9%, versus 97.9% without geometry, 98.2% without memory, and 96.5% for the bare backbone. On LIBERO-Long, removing memory reduces success from 96.6% to 94.2%. Two real-robot platforms cover 5 tasks and 50 total evaluations, averaging 78%, with 60 demonstrations per task. Each benchmark receives specific adaptation, and cross-paper scores are not strictly controlled comparisons. Memory resets each episode.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.29866) · [v1 abstract](https://arxiv.org/abs/2610.29866v1) · [Full text](https://arxiv.org/html/2610.29866v1) · [Author project link (unavailable at check)](https://geomem-vla.github.io/) · [Author code link (404 at check)](https://github.com/GeoMem-VLA/GeoMem-VLA). The author-provided project and code links returned 404 at the batch check. The paper promises release after publication; an available implementation was not verified.


<a id="arxiv-2610.29282"></a>

### Relational Geometry Forcing for World Action Models

**Metadata:** arXiv 2610.29282v1 · New paper · First submitted 2026-10-21 UTC. Review: Full-text experiments and ablations checked.

**Contribution:** Relational Geometry Forcing aligns within-frame, cross-view, and action-temporal relations with a frozen VGGT geometry prior. Training-only relational supervision avoids constraining compact action representations through pointwise feature alignment.

**Evidence and limitations:** Franka evaluation covers 4 base tasks and 3 generalization settings, with 20 trials per condition and the same 50 demonstrations per task. Average success is 65.71%, versus Fast-WAM at 57.14% and π0.5 at 54.29%. Across 3 WAM paradigms on LIBERO, gains are only 0.55–1.05 percentage points. The action-temporal term alone is detrimental; combining all 3 terms works best. Scale, contact, and long-horizon dynamics remain unresolved.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.29282) · [v1 abstract](https://arxiv.org/abs/2610.29282v1) · [Full text](https://arxiv.org/html/2610.29282v1). No official code or project link was found in the paper review.


<a id="arxiv-2610.29168"></a>

### How Representational Priors Shape Generalization in World Action Models

**Metadata:** arXiv 2610.29168v1 · New paper · First submitted 2026-10-21 UTC. Review: Full-text Table 1 and methods checked.

**Contribution:** This study measures, before training, how orthogonal visual perturbations are to an empirical in-distribution subspace. It examines the association between this representational property and subsequent WAM robustness.

**Evidence and limitations:** On LIBERO-Plus, FLUX.2 averages 89.0%, versus 63.9% for the same architecture with random initialization; Wan2.2 reaches 46.5%. These are correlations across backbones. Some baseline results are taken from their original papers, and pretraining, model size, and action heads are not fully matched. The evidence does not establish that orthogonality causes better generalization. Evaluation is simulation-only and does not demonstrate cross-embodiment transfer or continual adaptation.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.29168) · [v1 abstract](https://arxiv.org/abs/2610.29168v1) · [Full text](https://arxiv.org/html/2610.29168v1). No official code or project link was found in the review.


<a id="arxiv-2610.29246"></a>

### DepState-JEPA: Learning Depth-Grounded State Representation for Visual Perception and Manipulation

**Metadata:** arXiv 2610.29246v1 · New paper · First submitted 2026-10-21 UTC. Review: Full-text Table 3 and appendix limitations checked.

**Contribution:** DepState-JEPA learns a shared RGB-D latent state by jointly predicting future features, robot state, and kinematic consistency. It supports learning from imagined trajectories and latent-space model predictive control.

**Evidence and limitations:** A frozen simulation-trained model reaches 81.1% on drawer tasks and 78.9% on cup tasks in matched real-robot scenes, versus V-JEPA2.1-AC at 66.7% and 64.4%. Evaluation uses 3 seeds with 30 trials per seed. The setup includes PRISM depth enhancement, fixed calibrated cameras, and embodiment-specific training. Its 60-second execution budget excludes inference and search time, so the results do not establish real-time cross-embodiment transfer.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.29246) · [v1 abstract](https://arxiv.org/abs/2610.29246v1) · [Full text](https://arxiv.org/html/2610.29246v1). No official code or project link was found in the review.


<a id="arxiv-2610.28814"></a>

### T-WLA: Bridging Slow Vision and Fast Touch

**Metadata:** arXiv 2610.28814v1 · New paper · First submitted 2026-10-20 UTC. Review: Full-text Table 2 and ablations checked.

**Contribution:** T-WLA caches visual history while a tactile editor directly corrects action chunks that have not yet executed. Future-image and pressure prediction provide training supervision only. Its memory is episode-local context.

**Evidence and limitations:** With 30 teleoperated demonstrations per task, mean success over 4 real-robot tasks is 50.0%. The no-touch variant already reaches 47.25%, versus SmolVLA with touch at 17.0%; the full 33-percentage-point difference cannot be attributed to touch alone. Visual and tactile frequencies are 39.7 Hz and 119.1 Hz, respectively. Cup nesting remains at 17%.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.28814) · [v1 abstract](https://arxiv.org/abs/2610.28814v1) · [Full text](https://arxiv.org/html/2610.28814v1) · [Project and demonstrations](https://anonymous-submission-20.github.io/T-WLA.github.io/). The project demonstrations were accessible, but no usable code link was found. The abstract's wording is insufficient to label the method open source.

## Online learning and sim-to-real transfer


<a id="arxiv-2610.29117"></a>

### Learning to Absorb Corrections: Critic-Weighted Residual Flow for Vision-Based Insertion

**Metadata:** arXiv 2610.29117v1 · New paper · First submitted 2026-10-21 UTC. Review: Full-text experiments and ablations checked.

**Contribution:** ACT–Flow feeds successfully executed actions back into ACT and recomputes residual labels as the base policy changes. A critic trained on successful and failed experience weights residual flow. Evaluation with the residual disabled at the same checkpoint provides evidence of correction absorption: ACT success rises from 16% to 76%.

**Evidence and limitations:** Across 5 real-robot tasks and 3 training seeds, average success reaches 66% after 20k interaction steps, versus 48% for the strongest FTC baseline, and 87% after 60k steps. Freezing ACT, using uniform weights, or removing success supervision each degrades performance. Interaction steps are matched across methods, but human anchors, warmup, and compute are not fully aligned. The backbone is ACT rather than a VLA, and cross-task resistance to forgetting is not validated.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.29117) · [v1 abstract](https://arxiv.org/abs/2610.29117v1) · [Full text](https://arxiv.org/html/2610.29117v1). No official code or project link was found in the review.


<a id="arxiv-2610.29264"></a>

### Training in Deployment: Human-in-the-loop Online Post-Training for Robot Manipulation

**Metadata:** arXiv 2610.29264v1 · New paper · First submitted 2026-10-21 UTC. Review: Full text and project results checked.

**Contribution:** TIDE tracks whether actions come from a human or a policy and updates a world action model without a critic, publishing a checkpoint after every 5 successful episodes. Humans still select successful trajectories, and chunks mixing action sources are discarded.

**Evidence and limitations:** On dual UR5e robots, 4 tasks receive 20 trials each. Full-completion counts are 16, 13, 17, and 16, versus 16, 12, 16, and 14 for a budget-matched Fixed Policy. Final performance is similar; the main advantage is access to updated policies during the session. The reported under-1-hour-per-task process uses 8 × H100 GPUs and excludes initial setup and final evaluation. There is no evidence of continual learning across tasks.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.29264) · [v1 abstract](https://arxiv.org/abs/2610.29264v1) · [Full text](https://arxiv.org/html/2610.29264v1) · [Project](https://logosroboticsgroup.github.io/TIDE/) · [Repository (project website at check)](https://github.com/LogosRoboticsGroup/TIDE). The repository contained a project website and README at the batch check; released training code was not verified.


<a id="arxiv-2610.29161"></a>

### SimPT: An Automated Simulation Framework for Intervention-Based VLA Post-Training

**Metadata:** arXiv 2610.29161v1 · New paper · First submitted 2026-10-21 UTC. Review: Full-text tables and real-robot description checked.

**Contribution:** SimPT uses privileged simulation state to drive a progress graph, stores stage snapshots, and uses CuRobo to backtrack and recover. It automates intervention-data collection for π0.5 VLA post-training comparisons.

**Evidence and limitations:** Across 7 tasks, methods share initialization, 240 collection seeds, 10k training steps, and 1,400 evaluations. HG-DAgger reaches 82.14%, versus RECAP at 76.50%; modified RECAP reaches 79.36% and still trails HG-DAgger. Real-robot results of 24/25 versus 18/25 use the same 1,672 real trajectories. This supports transfer of an algorithmic modification, not zero-shot sim-to-real policy transfer. Reported confidence intervals are conditional on the trained policies; uncertainty across independent training seeds was not identified.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.29161) · [v1 abstract](https://arxiv.org/abs/2610.29161v1) · [Full text](https://arxiv.org/html/2610.29161v1). No official code or project link was found in the review.


<a id="arxiv-2610.28880"></a>

### Real2Sem2Real: 3D Semantic Augmentations for Robot Learning from a Single Human RGB Demonstration

**Metadata:** arXiv 2610.28880v1 · New paper · First submitted 2026-10-20 UTC. Review: Full-text comparisons and project checked.

**Contribution:** Real2Sem2Real tracks objects and aligns functional parts in a single human RGB demonstration. It generates digital cousins and synthetic robot demonstrations to train π0.5 with LoRA, expanding data across objects.

**Evidence and limitations:** The evaluation spans 2 robots and 4 tasks. With the same video and 2,000 synthetic episodes, the method exceeds a no-cousins control by 26–54 percentage points. On xArm cup placement, it achieves 90%, versus 62% from 150 teleoperation demonstrations, but dataset sizes and optimization steps are unmatched. Switching to MuJoCo rendering reduces success to 62%. Object-size measurements and scene setup remain necessary. The method primarily treats rigid objects and kinematic object carrying; it is not online skill learning.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.28880) · [v1 abstract](https://arxiv.org/abs/2610.28880v1) · [Full text](https://arxiv.org/html/2610.28880v1) · [Project](https://real2sem2real.github.io/). The project explicitly marked code as coming soon.


<a id="arxiv-2610.28948"></a>

### COWBOY: A Scalable Sim-to-Real Framework for Learning Contextual Whole-Body Manipulation

**Metadata:** arXiv 2610.28948v1 · New paper · First submitted 2026-10-20 UTC. Review: Full text and real-robot ablations checked.

**Contribution:** COWBOY combines local RL grasping experts with an environment-aware whole-body controller, then distills them into a point-cloud policy. It studies reuse of local manipulation abilities in broader whole-body contexts.

**Evidence and limitations:** Grasping success is approximately 91% across 24 real-robot scenes. Removing active vision reduces it to 46.7%; removing LiDAR reduces it to 71.1%. Simulation success is 92.4%, versus ManipGen at 63.1%. End-to-end RL reaches 0% in complex scenes but 96% without obstacles, so the results do not show that end-to-end RL is generally ineffective. Expert training takes approximately 36 hours on an A6000; student training takes 60 hours on 8 GPUs. Language only selects the target, there is no continual learning during deployment, and compute is not strictly matched.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.28948) · [v1 abstract](https://arxiv.org/abs/2610.28948v1) · [Full text](https://arxiv.org/html/2610.28948v1) · [Project](https://cowboy-manip.com/). No implementation link was found on the project page.


<a id="arxiv-2610.30097"></a>

### AtomicRL: Atomic Reinforcement Learning for Long-Horizon Robotic Manipulation

**Metadata:** arXiv 2610.30097v1 · New paper · First submitted 2026-10-21 UTC. Review: Full-text experiments and appendix checked.

**Contribution:** AtomicRL gates TD residuals at failed atomic-subtask boundaries and directs exploration toward bottlenecks. Progress and completion signals guide long-horizon RL, with the emphasis on credit assignment and allocation of exploration budget.

**Evidence and limitations:** On LIBERO-LONG, π0.5 PPO success rises from 95.4% to 99.0%; CALVIN five-task sequence completion rises from 70.6% to 80.1%. Three AgiBot G1 tasks use 100 SFT demonstrations and 25 evaluations each. Real-robot averages are SFT 48.0%, PPO 61.3%, and AtomicRL 69.3%. The abstract's +21.3-point gain is relative to SFT; the gain over PPO is only 8.0 points. RL runs in reconstructed simulation and depends on atomic task structure, progress judgments, and an initial policy. It does not demonstrate autonomous continual learning directly in deployment.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.30097) · [v1 abstract](https://arxiv.org/abs/2610.30097v1) · [Full text](https://arxiv.org/html/2610.30097v1). No official code or project link was found in the review.

## Substantive revisions and new evidence


<a id="arxiv-2607.00272"></a>

### ASPIRE: Agentic /Skills Discovery for Robotics

**Metadata:** arXiv 2607.00272v2 · Revised paper · First submitted 2026-06-30 UTC; revised 2026-10-20 UTC. Review: v1/v2 full-text comparison.

**Contribution and revision:** Version 2 adds online skill learning on a real robot, backward-transfer experiments, and model/cost scaling experiments. A frozen model accumulates experience in a textual skill library, extending the evidence for cross-episode skill accumulation.

**Evidence and limitations:** On a dual-arm YAM robot, one GPT-6 Astra session plays 3 Rubik's Cube rounds. Time per completed face rotation falls from 16 min 58 s to 7 min 48 s to 3 min 05 s. The first round is unsolved; total solving times for the next two are 39 min and 77 min 10 s, so overall solving time does not decrease monotonically. More debugging raises performance across 20 tasks from 74.6% to 82.2%, with a larger budget. Humans still provide initial guidance and resets; the API is fixed, and a skill is validated once before entering the library. The method is not gradient-based RL and lacks an independent causal control.

### HarnessPAI: An Evolving Harness for Physical AI

**Metadata:** arXiv 2609.29166v2 · Revised paper · First submitted 2026-09-24 UTC; revised 2026-10-21 UTC. Review: v1/v2 full-text and table comparison.

**Contribution and revision:** Version 2 adds DreamZero WAM fine-tuning through supervised learning on successful harness trajectories. This connects cross-rollout code repair and skill accumulation with model updates.

### Feedback World Model Enables Precise Guidance of Diffusion Policy

**Metadata:** arXiv 2605.15705v2 · Revised paper · First submitted 2026-05-15 UTC; revised 2026-10-21 UTC. Review: v1/v2 full-text and new-table comparison.

**Contribution and revision:** Version 2 extends the method to a frozen Fast-WAM-Joint model. Observation–prediction residuals update a lightweight exponential-moving-average feedback state. New experiments decompose disturbances and compare Kalman-filter/RSSM alternatives and gain settings. This is state adaptation rather than parameter training or skill expansion.

**Evidence and limitations:** Across 393 OOD initial-state variants and 7,553 prediction pairs, gain 0.5 reduces latent MSE by 18.3%, and OOD success rises from 77.1% to 81.4%. Gain 1 worsens MSE by 8.6%–20% on 4 tasks. The theory additionally requires bounded, asymptotically convergent residuals and a stable gain.
