### Externalise the Memory: A Pre-Registered Study of Where an Embodied Agent's Experience Should Live

**Metadata:** arXiv 2610.30478v1 · New paper · First submitted 2026-10-21 21:54:57 UTC. Review: Full-text methods, experiments and limitations checked; Preregistered controlled simulation; narrow scope; second-task replication inconclusive.

**Contribution:** A preregistered study compares LoRA consolidation with inference-time retrieval of visual episodic lessons. Its cleanest comparison toggles a frozen memory buffer while keeping policy weights fixed.

**Evidence:** In a single-arm reaching simulation, 100 episodes per arm give 15%→49% success with retrieval (+34 percentage points). Distillation adds only one point over action-only supervision. On harder dual-arm reaching, retrieval adds six points, with a 95% interval of −4.5 to +16.4 points. Follow-up adapter controls support retrieval's benefit without requiring an adapter.

**Limitations:** The distillation null is underpowered, not evidence that parametric memory cannot work. Scope is narrow; retrieval combines text and images, and reset/logging defects require sensitivity analyses. The public repository is verified, but its claimed artifact release was absent when checked.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.30478) · [Reviewed version](https://arxiv.org/abs/2610.30478v1) · [Full text](https://arxiv.org/html/2610.30478v1) · [PDF](https://arxiv.org/pdf/2610.30478v1) · [Code](https://github.com/TPEmist/AionGenos) · [reproduction_guide](https://github.com/TPEmist/AionGenos/blob/master/docs/paper/REPRODUCE.md). ### FastHarness: Experience-Driven Review Scheduling for Vision-Language-Action Policies

**Metadata:** arXiv 2610.31427v1 · New paper · First submitted 2026-10-22 15:27:10 UTC. Review: Full-text methods, experiments and limitations checked; Descriptive persistent-memory simulation chains; non-matched external success comparator.

**Contribution:** FastHarness schedules GPT-6 Astra reviews of a frozen π0.5 policy using persistent stage and failure memory. Familiar execution skips reviews; risky states and recovery receive closer supervision without additional model training.

**Evidence:** Across four RoboDojo tasks and 65 episodes, the unweighted mean task success is 97.19%. Comparing each first evaluated episode with its final-five mean yields a 57.2% mean token reduction and 85.5→52.0 minutes per episode. Public code, tests and integration interfaces are available.

**Limitations:** The 80% comparison baseline is borrowed from another report, with five cases per task and a different scene mix, not a matched rerun. Episodes share memory and are not independent; the first tower episode already has prior experience. Savings are descriptive within-chain changes, not an end-to-end A/B effect. Evaluation is simulation-only and includes missed failures. The 57.2% is the mean of per-task percentage reductions, not the change in aggregate mean tokens. Token counts include input, output and cached inputs; they are not monetary costs.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.31427) · [Reviewed version](https://arxiv.org/abs/2610.31427v1) · [Full text](https://arxiv.org/html/2610.31427v1) · [PDF](https://arxiv.org/pdf/2610.31427v1) · [Code](https://github.com/FastHarness/fast-harness) · [Project](https://fastharness.github.io/). Public MIT repository verified, including fast_harness, tests, docs, offline demo and live integration interfaces. RoboDojo runtime and policy server must be supplied separately.

### Know When to Escalate: Critic-Guided Adaptive Execution for Cloud-Local Embodied Agents

**Metadata:** arXiv 2610.30587v1 · New paper · First submitted 2026-10-22 01:38:34 UTC. Review: Full-text methods, experiments and limitations checked; Matched multi-benchmark simulation plus memory/model ablations; no physical deployment.

**Contribution:** CARE uses a critic to transfer execution from a local model to a stronger cloud model, retains cloud control through recovery, and shares persistent handoff memory across executors.

**Evidence:** On 120 Habitat, 80 EmbodiedBench and 80 VLABench instances, success reaches 92.5%, 75.0% and 87.5%. Gains over the strongest collaboration baseline are 18.3, 16.2 and 6.3 percentage points. Median time between actions falls 28.8–82.6% versus cloud-only execution. Baselines share models, instances and memory representation; some are benchmark-specific adaptations.

**Limitations:** These are simulated decision-layer results, not physical robot response times. Local execution and criticism run on H200 GPUs. Thresholds are benchmark-tuned, and cloud-request ratios exclude critic calls. Network variability, sensing noise and hardware failures remain untested; no official code link was located. On EmbodiedBench, CARE remains below cloud-only success (75% versus 80%); the cloud-request ratio is not total compute cost.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.30587) · [Reviewed version](https://arxiv.org/abs/2610.30587v1) · [Full text](https://arxiv.org/html/2610.30587v1) · [PDF](https://arxiv.org/pdf/2610.30587v1). No official project or code link located in abstract, full text, PDF hyperlinks or targeted search; this is not proof that no code exists.

### Memory before Goal: Role of Pre-History Memory for Humanoid Loco-Manipulation

**Metadata:** arXiv 2610.31166v1 · New paper · First submitted 2026-10-22 UTC. Review: Full-text methods, key experiments and limitations checked.

**Contribution:** WholeBodyMem selects historical frames from SAM3 object events and supplies object spatiotemporal tokens and memory attention to a whole-body action expert.

**Evidence:** On six simulated HuMeGo tasks, success is 72.6%, versus 29.1% without memory and 44.4% with uniform memory. Event selection alone at the matched seven-frame budget reaches 60.4%. Six G1 tasks, 60 trials per method, improve from 22/60 to 53/60 (36.7% to 88.3%).

**Limitations:** This is within-episode perceptual history, not cross-episode skill accumulation. Physical tests have only ten trials per task and no uniform-memory real-robot comparator. Missed SAM3 detections and tracking overhead remain limitations.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.31166) · [Reviewed version](https://arxiv.org/abs/2610.31166v1) · [Full text](https://arxiv.org/html/2610.31166v1) · [Project](https://memory-before-goal.github.io/). ### DeXplicit: Making Physical State Explicit in Dexterous Manipulation World Models

**Metadata:** arXiv 2610.30781v1 · New paper · First submitted 2026-10-22 06:02:09 UTC. Review: Full-text methods, key experiments and limitations checked; author-reported results, not independently reproduced.

**Contribution:** DeXplicit predicts object-centric motion and deformation in metric 3D before rendering action-conditioned video. Matched-input comparisons reduce long-horizon moved-point error 27–40% versus adapted PointWorld; explicit geometry improves object fidelity.

### DRILL: Training World Models to Improve Policies, Not Predict Pixels

**Metadata:** arXiv 2610.30814v1 · New paper · First submitted 2026-10-22 06:40:31 UTC. Review: Full-text methods, key experiments and limitations checked; author-reported results, not independently reproduced.

**Contribution:** DRILL trains a world model for the policy improvement its imagined rollouts produce. A cheaper visitation/advantage/confidence-weighted surrogate and a bilevel meta-gradient variant target downstream return instead of pixel fidelity.

**Evidence:** Across five manipulation simulators on π0-3B, DRILL-IMG reports +13.1 pp mean success over WMPO and +7.9 pp over RLVR-World, despite 17% worse one-step pixel MSE. LIBERO-Long 81.3±1.3 vs WMPO 64.2±1.6; five seeds for headline results, three for ablations. Two-backbone study including OpenVLA; circa 17k H20 GPU-hours total reported; DRILL-IMG uses 30 simulator rollouts per outer update.

**Limitations:** Entirely simulation-only. “Real rollouts” in the notation mean simulator interaction, not physical robots. Meta-gradients add compute/memory; VWI and IMG are statistically tied on SimplerEnv.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.30814) · [Reviewed version](https://arxiv.org/abs/2610.30814v1) · [Full text](https://arxiv.org/html/2610.30814v1). Code and trained checkpoints promised; no verified public repository linked in paper

### When One Step Is Enough: An Empirical Study of Euler Integration in Flow-Matching Policies

**Metadata:** arXiv 2610.30735v1 · New paper · First submitted 2026-10-22 UTC. Review: Full-text methods, key experiments and limitations checked.

**Contribution:** Tests one Euler step using existing flow-matching checkpoints across six VLAs and a DiT, without additional one-step distillation.

**Evidence:** For π0.5, action-generation latency on A100 drops from 80 to 50 ms. Four Franka tasks, 100 trials per task and setting, yield pooled success of 79.0% versus 78.5%. Simulation uses official checkpoints and probes training maturity, scale and diversity.

**Limitations:** Similar aggregates do not establish per-task real-world equivalence: close-oven falls from 87% to 74%, and the physical evaluation cannot resolve its preregistered equivalence margins. Smaller models can degrade on long horizons; one-step RL updates are untested.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.30735) · [Reviewed version](https://arxiv.org/abs/2610.30735v1) · [Full text](https://arxiv.org/html/2610.30735v1) · [Project](https://onestepflow.github.io/) · [Code](https://github.com/lucanunz/flowsteps_corl2026). **Metadata:** arXiv 2610.31423v1 · New paper · First submitted 2026-10-22 UTC. Review: Full-text methods, key experiments and limitations checked.

### Echo: Coupled Action and Task Status Signal Denoising for Vision Language Action Models

**Metadata:** arXiv 2610.31569v1 · New paper · First submitted 2026-10-22 17:12:16 UTC. Review: Full-text methods, experiments and limitations checked; Five-task physical study with matched action baseline, ablations, and larger fixed-scene simulation evaluation.

**Contribution:** Echo jointly denoises actions plus stop/failure signals. Structured attention and faster signal denoising let cleaner status estimates guide action generation. Success, failure and recovery trajectories supply supervision without frame-level progress labels.

**Evidence:** Five real tasks use 30 trials per model/task. Flower insertion completion score rises from 5.67 to 8.33/10, with 92.18% frame-level status F1. Across 4,500 LIBERO-Recovery trials per model, success rises from 32.67% to 34.76%. RTX 4090 inference increases from 115 to 120 ms. Official simulation code is available.

**Limitations:** Real-world scores are not success rates. Action supervision and training budgets are matched, but Echo receives extra failure-status data. Cross-method comparisons focus on flower insertion with adapted protocols; two tasks have no failed evaluation episodes. Benefits from higher-level stopping or replanning integration remain untested. The three-second outcome-window F1 does not imply instantaneous failure detection; simulation status accuracy covers ongoing/success frames under a specified window, not general three-class failure detection.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.31569) · [Reviewed version](https://arxiv.org/abs/2610.31569v1) · [Full text](https://arxiv.org/html/2610.31569v1) · [PDF](https://arxiv.org/pdf/2610.31569v1) · [Project](https://lyfeng001.github.io/Echo/) · [Code](https://github.com/lyfeng001/Echo-Sim). Official project and public simulation repository verified. Repository contains Echo model, action baseline, training/evaluation code and data manifests; no real-world implementation release was verified.

### METTA: Memory-Enhanced Test-Time Adaptation for Meta-Reinforcement Learning

**Metadata:** arXiv 2610.31656v1 · New paper · First submitted 2026-10-22 17:58:27 UTC. Review: Full-text methods, key experiments and limitations checked; author-reported results, not independently reproduced.

**Contribution:** METTA separates fast gradient-updated within-episode neural memory from compact cross-episode summaries. It reports over 50% success on held-out Meta-World ML10/45 task families and better long-context sparse-reward exploration.

**Evidence:** Five seeds; PointMaze coverage 0.447±0.036 vs ECET 0.250±0.087; success/termination steps 194.8±30.1 vs 427.3±44.5. At horizon 500, TTT-MLP reports 2.16 ms/step and 5.03 MiB; 4.3× lower latency than TrMRL.

**Limitations:** State-based meta-RL rather than a visual VLA; ML10/45 include goal coordinates in observations. Task remains fixed across episodes in a trial. Fast memory is reset each episode and episode summaries are retained; continual/nonstationary task changes remain future work. Disabling within-episode updates changes ML10 little but hurts hidden-goal/sparse-feedback tasks, limiting a blanket TTA interpretation.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.31656) · [Reviewed version](https://arxiv.org/abs/2610.31656v1) · [Full text](https://arxiv.org/html/2610.31656v1). Supplementary code claimed; complete public repository promised upon acceptance, no verified public link

### Asking Less, Adapting Better: Feedback-Efficient Test-Time Adaptation for Vision-and-Language Navigation

**Metadata:** arXiv 2610.30643v1 · New paper · First submitted 2026-10-22 03:05:25 UTC. Review: Full-text methods, key experiments and limitations checked; author-reported results, not independently reproduced.

**Contribution:** FETA makes test-time navigation updates from one binary feedback label on a selected action. It selects unstable trajectories, locates high entropy-gradient steps, and weights updates by policy–feedback disagreement.

**Evidence:** REVERIE unseen relative SPL gains over ATENA: 18.30%, 26.21%, 15.34% for DUET, GOAT, ScaleVLN; fewer feedback queries. ### Learning Robot Behavior Priors from Non-Robotic Synthetic Data

**Metadata:** arXiv 2610.31275v1 · New paper · First submitted 2026-10-22 UTC. Review: Full-text methods, key experiments and limitations checked.

**Contribution:** Pretrains a Transformer on procedural non-robotic MDP, contextual-bandit and linear-dynamical-system data, then predicts unseen robot actions from in-context examples.

**Evidence:** On four real-robot datasets with 64 action classes, control priors achieve mean accuracy 0.166 versus 0.039 for generic tabular priors across three seeds. A real-data comparator uses the same architecture and training budget.
