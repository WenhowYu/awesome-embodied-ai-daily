### MOTIO: Agentic Skill Engineering for Reality-Grounded Humanoid Loco-Manipulation

**Metadata:** arXiv 2610.33446v1 · New paper · First submitted 2026-10-24 04:55:00 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** MOTIO turns human-action videos, metric 3D assets and existing robot-control interfaces into staged humanoid programs, revising them through physics feedback and human approval; generated skills also supervise BC/DAgger distillation.

**Evidence:** 33 timestamped first approvals have median 97 agent-turn minutes and 2.80 calendar hours. A G1 bottle-disposal execution lasts 101.75 seconds; one shared distilled checkpoint completes 18 simulated tasks.

**Limitations:** Human approval and task-specific engineering remain central. Physical demonstrations and simulated variation tests are not a randomized real-robot success benchmark; development time includes tool/resource waits. Distillation evidence is simulation-side.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.33446) · [Reviewed version](https://arxiv.org/abs/2610.33446v1) · [Full text](https://arxiv.org/html/2610.33446v1) · [Project](https://iiiiqiiii.github.io/motio/). Project page verified; no paper-specific source repository identified on it.

### ReSight: Task-Driven Self-Improving Memory for Embodied Agents

**Metadata:** arXiv 2610.33487v1 · New paper · First submitted 2026-10-24 06:32:18 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** ReSight separates immutable observation evidence from extensible derived fields. Explore–Distill–Mount uses a higher-budget coding agent to create reusable memory builders, tools and skills for a fixed-budget executor, without reference answers.

**Evidence:** FindingDory rises from 38.3% to 63.8% on 596 queries; frozen tools on 597 excluded-episode queries improve 37.5% to 65.8%, with mean tokens/query 128.8k to 39.4k. OC-NaVQA mean position error falls 33.10 m to 24.72 m on 210 questions.

**Limitations:** Online savings exclude separate exploration, model preparation and memory-building costs. This is historical-observation QA, not closed-loop manipulation; OC-NaVQA binary accuracy decreases 86.6% to 82.1%. Long-term repeated capability expansion remains untested.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.33487) · [Reviewed version](https://arxiv.org/abs/2610.33487v1) · [Full text](https://arxiv.org/html/2610.33487v1). No official paper-specific code or project link identified in the abstract/full text.

### RoboJev: An Open Vision-Language Judge for Robot Success Detection

**Metadata:** arXiv 2610.33718v1 · New paper · First submitted 2026-10-24 15:06:27 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** RoboJev-27B adapts JEV-27B-VL with language-only rank-32 LoRA and source-specific KL anchoring, then predicts success with a calibrated two-token readout from ten primary frames plus available auxiliary final frames.

**Evidence:** 268 SO-101 episodes yield 95.2% balanced accuracy and 0.993 AUROC. Across 459 unseen-domain episodes AUROC is 0.890 versus the matched-input base model’s 0.900. Serial H100 inference median is 0.257 s, modeled at $0.19/1,000 judgments.

**Limitations:** Only 80/268 SO-101 episodes are held-out tasks. API baselines receive four primary frames, so frontier comparisons are not input-matched. Cost excludes media/serving overhead; community labels have one annotator; calibration and safety transfer are unestablished.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.33718) · [Reviewed version](https://arxiv.org/abs/2610.33718v1) · [Full text](https://arxiv.org/html/2610.33718v1) · [Checkpoint](https://huggingface.co/josefchen/RoboJev-27B) · [data](https://huggingface.co/datasets/josefchen/RoboJev-evals). Public Hugging Face model and evaluation dataset APIs verified; repository lists weights and inference assets, not executed.

### RoboDuo: Attempt, Check and Atomic Recovery through Code for Vision-Language-Action Models

**Metadata:** arXiv 2610.34108v1 · New paper · First submitted 2026-10-25 07:08:25 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** RoboDuo lets a full-task VLA attempt the task, checks completion, then uses a separately trained atomic VLA through generated code to recover unfinished steps while keeping the full-task policy frozen.

**Evidence:** With four-suite training, π0.5 LIBERO-PRO mean success rises 32.05% to 39.33%; Astra coding reaches 41.50% (43.00% with TAMP). Real bimanual fruit arrangement, 10 trials/layout, changes 40/30/40% to 60/60/40%.

**Limitations:** Not training-free overall: atomic policy and completion-checking coding agent use derived demonstration datasets. Gains shrink with five-suite training; real evaluation is one task family with small counts. Published reference rows use different protocols and are not matched reruns.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.34108) · [Reviewed version](https://arxiv.org/abs/2610.34108v1) · [Full text](https://arxiv.org/html/2610.34108v1). No official paper-specific code or project link identified in the abstract/full text.

### ThinkLocoManip: A Whole-Body Control Agentic Harness for Legged Loco-Manipulation

**Metadata:** arXiv 2610.34370v1 · New paper · First submitted 2026-10-25 15:23:26 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** ThinkLocoManip interleaves reasoning and action over perception, navigation, manipulation and whole-body locomotion tools; keyframe thinking retains execution context for recovery.

**Evidence:** On a real wheeled quadruped with Piper arm, 54/70 trials succeed (reported 77.0%) versus 26/70 (37.1%) for plan-then-act. On the three-task ablation subset, removing keyframe thinking drops success from 82% to 64%.

**Limitations:** Five task families on one platform, 10–20 trials per task. Tool orchestration includes engineered navigation/grasp/control capabilities; these results do not isolate cross-episode skill acquisition or establish portability of the whole-body controller.

### How High Can GPT-6 Astra Climb in Contact-Rich Manipulation? PhysLadder: A Hierarchical, Matched Sim-Real Benchmark for Physical Interaction

**Metadata:** arXiv 2610.34527v1 · New paper · First submitted 2026-10-25 19:41:02 UTC. Review: Full-text key methods and experiments checked.

### VISTA: Active Exploration for Self-Improvement in Embodied Agents

**Metadata:** arXiv 2610.35051v1 · New paper · First submitted 2026-10-26 09:00:17 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** VISTA evolves executable robot-agent harnesses using an ancestry graph, active diagnostic interactions and fresh autonomous evaluation of frozen candidate packages, without updating model weights.

**Evidence:** Selected per-task harnesses raise LIBERO-Pro success 17.5% to 95.0%, RoboTwin 48.5% to 74.0%, and RoboCasa unseen composites 4.7% to 13.3%. Four-task active/passive ablation after two rounds: +85.9/+56.3 points at 91.6M/137.7M cumulative meta tokens per task.

**Limitations:** Simulation only. Task-specific selection and best-so-far curves do not prove unseen-task generalization or monotonic candidate improvement. Up to 100 planner turns and 10,000 physics steps on LIBERO-Pro/RoboTwin; development compute is substantial and baseline budgets must not be assumed matched.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.35051) · [Reviewed version](https://arxiv.org/abs/2610.35051v1) · [Full text](https://arxiv.org/html/2610.35051v1) · [Project](https://agenticei.github.io/VISTA-page/) · [Code](https://github.com/AgenticEI/VISTA). **Metadata:** arXiv 2610.35172v1 · New paper · First submitted 2026-10-26 10:35:50 UTC. Review: Full-text key methods and experiments checked.

**Metadata:** arXiv 2610.34151v1 · New paper · First submitted 2026-10-25 08:37:41 UTC. Review: Full-text key methods and experiments checked.

### Evolving to Match Capabilities: Improving Harness Self-Evolution via Skill Adaptation

**Metadata:** arXiv 2610.33024v1 · New paper · First submitted 2026-10-10 04:44:35 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** Skill Adaptation turns diagnosed executor weaknesses into a meta-skill for rewriting procedural skills, then compares one-shot rewriting and five rounds of feedback-driven self-evolution across executor capacities.

**Evidence:** On 103 selected skill-sensitive task/skill pairs, Kimi-K3 rewriting raises mean weak-executor score from 0.294 to 0.387, while weak self-rewriting lowers it to 0.271. With failure traces, all seven executors finish round five above the no-meta-skill arm, by 0.020–0.051.

**Limitations:** Non-robotic STEM/document/developer tasks, selected from 607 tasks for skill sensitivity. Each evolution round runs once; small gaps have no repeated-run uncertainty estimate. Skills are already in context, so retrieval, progressive disclosure and closed-loop physical transfer are untested.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.33024) · [Reviewed version](https://arxiv.org/abs/2610.33024v1) · [Full text](https://arxiv.org/html/2610.33024v1) · [Project](https://zhihaoyang30.github.io/skill-adaptation/). ### MOON: Learning When to Forget and How to Move On in Vision-and-Language Navigation

**Metadata:** arXiv 2610.33546v1 · New paper · First submitted 2026-10-24 08:50:29 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** MOON adds a deviation judge and GRPO-trained recovery adapter to a frozen vision-language navigation policy: an alarm clears visual history once, then recovery learns to escape history-induced behavioral inertia.

**Evidence:** Full val-unseen splits contain 1,839 R2R-CE and 3,669 RxR-CE episodes. R2R success rises from the frozen base’s 63.8% to 69.0%; judge+clearing alone gives 65.6%, while random clearing+recovery gives 60.4%. Added parameters are 36M (0.81%).

**Limitations:** Simulation only; deployment tested on one backbone and trains two adapters, not training-free. Alarm operating levels were selected on the reported evaluation splits. Clearing breaks 5.8%/4.1% of base-success episodes on R2R/RxR; successful forgetting is not evidence that long-term skill memory should be deleted.

**Resources:** [arXiv record](https://arxiv.org/abs/2610.33546) · [Reviewed version](https://arxiv.org/abs/2610.33546v1) · [Full text](https://arxiv.org/html/2610.33546v1) · [Code](https://github.com/AutoLab-SAI-SJTU/MOON). Public repository contains inference/evaluation harness and tests; training is explicitly coming after acceptance. Weights not downloaded and code not run.

### MemVLN: Streaming Episodic Memory for Vision-Language Navigation

**Metadata:** arXiv 2610.35066v1 · New paper · First submitted 2026-10-26 09:13:13 UTC. Review: Full-text key methods and experiments checked.

**Contribution:** MemVLN compresses episode-local visual features with timestamps and action-derived poses into a bounded bank and 300 cross-attention memory tokens, combining a frozen geometry encoder with trained memory, adapters and trajectory-summarization supervision.

**Evidence:** R2R/RxR val-unseen success is 55.0%/55.4%. On real G1, six held-out instructions repeated five times give base 5/30, memory-only 9/30, full model 12/30, and post-trained model 14/30 successes. Full and post-trained models both have 46.7% collision/contact rate.

### EKT-Router: Expert-Evidence Alignment for Embodied Vision-Language Models

**Metadata:** arXiv 2610.33044v1 · New paper · First submitted 2026-10-16 11:41:17 UTC. Review: Full-text key methods and experiments checked.
